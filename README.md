# Méro Cafe Demo

Αυτοτελές concept μονοσέλιδου επαγγελματικού site για καφετέρια και brunch.

## Προεπισκόπηση

Άνοιξε το `index.html` σε browser. Δεν χρειάζεται εγκατάσταση ή build.

## Αρχεία

- `index.html` — περιεχόμενο και βασικά metadata
- `styles.css` — responsive σχεδιασμός και φωτογραφίες από Unsplash
- `script.js` — φίλτρα μενού και πλοήγηση για κινητά

Το μενού περιλαμβάνει 17 αντιπροσωπευτικά προϊόντα σε έξι κατηγορίες, όχι πλήρη κατάλογο. Το όνομα, η τοποθεσία, το ωράριο και οι τιμές είναι ενδεικτικά. Οι φωτογραφίες, ο χάρτης και οι γραμματοσειρές φορτώνονται από το διαδίκτυο.
